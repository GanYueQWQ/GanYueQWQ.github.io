# 中文经济学与社科写作

这个技能做三件事，缺一件都会出问题：

1. **把经济学思维写出来**——不是把经济学名词贴上去，而是让论证按经济学的推理方式走；
2. **把中文 AI 腔去掉**——中文的 AI 指纹和英文不同，必须按中文的清单处理；
3. **把来源核实清楚**——引文、档案、课件的可核验程度必须标明，不许编造。

顺序不能颠倒：**先立论证，再改文风，最后核对来源**。文风再好也救不了一个没有推理结构的文章；反过来，一个论证扎实的文章即使偶有套话也是好文章。

---

## 第一部分：经济学思维清单

写这类文章时，逐项自检。跳过任何一项，读者（尤其是懂经济学的老师）都会看出来。

### 1. 先把博弈的要素摆出来，再讲道理

不要一上来就说"这是一个囚徒困境"。按标准要素写清楚：

- **参与人**（players）：是谁在决策？这一条最容易出错——单位层级不同，博弈就不同（个人、班排、营、司令部是两个不同的博弈）。
- **行动**（actions）：每人能选什么？
- **信息**（information）：对方能看到什么？看不到什么？
- **支付**（payoffs）：**写出矩阵或排序**，不要只用文字描述"好处""坏处"。数值可以是你按情形设定的，但**必须说明符号和大小顺序才是依据**。
- **均衡**（equilibrium）：纳什？子博弈精炼？贝叶斯？

一个 2×2 矩阵胜过三段形容词。

### 2. 区分"均衡存在"与"均衡选择"

这是最常见的失手处。写出一个合作是纳什均衡之后，**文章还没开始**：纳什均衡只说明"单方面改变没有好处"，它不解释"为什么会走到这个均衡"。

囚徒困境型博弈里谈"合作是均衡"通常是错的——**先检查占优策略到底是合作还是背叛**。如果合作是占优策略，那这个博弈更像保证博弈（stag hunt / 猎鹿，R > T > P > S）；如果是背叛占优而共同合作更好，才是囚徒困境（T > R > P > S）。**两种情形的政策含义完全不同**：囚徒困境要解决的是"背叛的诱惑"，保证博弈要解决的是"对方会不会也来"的不确定性。

### 3. 讲清机制的三个前提

"合作能维持"需要三个条件，逐条检查文章有没有交代：

- **激励**：未来足够重要吗（重复、贴现因子、关系的长度）？
- **执行**：参与人**有没有能力**自己执行承诺的策略？如果他控制不了自己下一期的行动，机制就失效——这是本文类文章最常见的切入点。
- **信息**：对方能观察到我的行动吗？观察不到就是隐藏行动问题；观察到但不知道原因（例如"被迫的背叛"）就是信号问题。

### 4. 把命题改写成可证伪的形式

不要停留在"某某理论有解释力但有局限"。要写成：

> 原来的说法是 A。我的改法是 A′。**A′ 与 A 做出不同的预测**：在某种情形下 A 预测 X，A′ 预测 Y。

写不出"改变什么预测"，说明这只是措辞修补，不是分析。

### 5. 用课件的判定标准收口

- **激励相容**：这套安排让每个人按它行事时，自己的收益是否不吃亏？
- **帕累托有效**：这个均衡好于哪个结果？没有更优的可行结果了吗？
- **是否符合个人理性**：如果一种制度安排不能满足个人理性，它就实行不下去（不能靠"应该"维持）。
- **制度必须是纳什均衡**：否则不成立。

### 6. 每个论断都要能落到支付表上的某一格

写完一段后自问：这句话在说哪一格收益、哪一次选择、哪一层参与人？落不到具体位置的话，多半是空话，删掉或改实。

### 7. 层级不要串

个人理性与集体理性冲突时，**说清是哪个集体**。"军队""国家""社会"的集体利益与个人的利益可能方向相反；把两个层级混在一句话里，论证会崩。典型句式："对士兵个人来说……而对司令部来说……，两者激励方向相反，而后者能覆盖前者的均衡。"

## 第二部分：去中文 AI 腔

### 中文的 AI 指纹（按抓取优先级排序）

**第一档：一看见就要改**

1. **对举句式**：`"不是 A，而是 B"`、`"A，却未必 B"`、`"既…也…"`、`"可能…也可能…"`、`"如果…；如果…"`。整篇靠这种平衡句撑起来的文章，人味为零。**判断标准：这一句的转折/并列两半是否都提供新信息？**只抬高语气的那一半删掉，直接说结论。
2. **句式节奏均匀**：每段长度接近、每句 30–45 字。人写的东西段落长短参差（短到一句话成段，长到 300 字），句长有 8 字也有 70 字。
3. **抽象名词密度过高**：条件、空间、动力、权限、代价、预期、利益、结构、机制、维度、层面、逻辑、边界……这些词本身没错，但如果全篇只有这些词、没有一件具体事（人名、地名、数字、动作、气味、对话），就是模型输出。**要用具体物象压过抽象名词。**

**第二档：出现多次就要改**

4. **限定词堆叠**：可能、也许、或许、未必、在一定程度上、需要指出的是。学术审慎是真的，但**每句都加限定等于什么都没说**。
5. **"进行+动词"**（进行讨论、进行分析）→ 直接用动词。
6. **"的"字层叠**：长定语改成短句。
7. **"随着……的发展/在……的背景下"式开头**：背景若不提供独立信息，删。
8. **四字格排比**：稳定可靠、快速响应、易于维护——除非真的是三项独立约束，否则改成人话。
9. **套话收尾**：综上所述、让我们拭目以待、期待更多可能。**有实际内容的总结可以留，纯祝愿删掉。**
10. **破折号当万能连接词**：中文里连续用 —— 是模型习惯。改成句号、逗号、冒号或括号。
11. **客服腔残留**：好问题！希望这对你有帮助！让我来为你分析。全删。
12. **拔高意义**：标志着、彰显了、具有重要意义、开启了新篇章。**保留事实，删掉意义**。

**第三档：看文体决定**

13. 粗体当装饰、表情符号、箭头 → 学术文本里删掉。
14. 强凑三段式（凑三样显得完整）→ 检查是否三项各自独立，否则合并。
15. 被动句与缺主语 → 施事者已知就改主动；未知就保留，**不要补造主语**。

### 改写纪律（比清单更重要）

- **不增加原文没有的事实、数字、人名、日期、引文、来源。** 需要细节时问用户，不要编。
- **不丢失信息**：否定、比较对象、范围、条件、时间、完成状态、归因。
- **不把"可能"改成"确定"**，不把"计划"写成"已完成"。
- **清单是线索不是禁令**：没有问题的段落原样保留，不要为改而改。
- **保留作者声音**：有范文（用户自己写过的段落）时，范文的句长、用词、标点习惯覆盖所有规则。不确定的地方问用户，比替他编一个好。

## 第三部分：来源核实纪律

社科与经济学文章的可信度全在这里。**每条引文都要标注可核验程度**：

| 标记 | 含义 |
| --- | --- |
| **已核对原文** | 直接读到转录/原文，逐字对齐 |
| **二手** | 只有研究著作或机构网页的转述，未读到原件——**正文里注明，或避免据此下判断** |
| **无法核实** | 穷尽检索没能读到，**必须在正文里明说，并给出档案号供读者自行核实** |
| **未采用** | 查不到可靠出处，**正文不用它**（但可以说明为什么不用） |

**硬规则：**

1. **绝不编造引文、档案号、页码、URL、数字。** 一处编造毁掉整篇文章的可信度。
2. **找不到出处的流行说法要标注出来**，并说明是在什么条件下不采用。这比默默用它强得多。
3. **区分"无法核实"与"有误"**——检索不到不等于史料错了，措辞要准。
4. **网页可能已下架**：注明"该页面已下架（返回 410）"，给出档案号或存档说明。别留死链当引用。
5. **课件要引页码**：写清是哪一次讲义、第几页、什么内容。
6. **正文里可以说出核实限度**："下面两条引文我逐字核对过，这一条没有"——这句话本身增加可信度，读者知道该信哪部分。

## 工作流程

1. **问清三件事**（缺任何一件就不要动笔）：
   - 要检验的**课堂观点原文**是什么？（让用户给课件/笔记）
   - 有没有**必须用的材料**（案例、事件、数据、指定文献）？
   - 这是**什么提交场合**（字数、格式、是否要求参考文献）？
2. **先搭论证骨架**：按第一部分七项走一遍，写出支付矩阵/条件分析/预测差异。骨架不对就不要润色文字。
3. **再写或改文字**：按第二部分清单处理。改了哪一类问题，能说清就告诉用户。
4. **最后核来源**：按第三部分逐条标记。有无法核实的就写进正文的"限度说明"。
5. **交付时说明**：论证靠什么、文风改了什么、哪些来源待核。

### 可选：先跑一遍量化自检

技能自带 `scripts/zh_style_check.py`，输出可复现的中文文风指标（段落与句长变异系数、对举句密度、限定词密度、抽象/具体词比、引号引用数），以及经济学内容配比（经济学词 vs 史实词）。

```bash
python scripts/zh_style_check.py 稿件.typ      # 也接受 .md/.txt
python scripts/zh_style_check.py 旧稿.typ 新稿.typ   # 对比
```

参考区间（本会话实测有效）：

| 指标 | 偏 AI | 自然 |
| --- | --- | --- |
| 段落长度 CV | < 0.2 | > 0.4 |
| 句长 CV | < 0.45 | > 0.6 |
| 对举句（每百字） | > 0.7 | < 0.55 |
| 模糊限定词（每百字） | > 1.2 | < 0.6 |
| 抽象词 : 具体感官词 | > 2 : 1 | < 1 : 1 |

指标是路标不是裁判。**指标达标但论证空心的文章仍然是坏文章**，不要为了凑指标而硬拆句子。

## 交付前核对

- [ ] 支付矩阵/条件分析写出来了吗？符号与顺序说明了吗？
- [ ] 分清"均衡存在"与"均衡选择"了吗？占优策略检查过了吗？
- [ ] 执行机制与信息机制交代了吗（不只是激励）？
- [ ] 我的改法**改变了什么预测**？
- [ ] 每个论断能落到具体某一格/某一层参与人吗？
- [ ] 对举句式、限定词堆叠、抽象名词密度处理了吗？
- [ ] 有没有为了改文风而丢掉信息、或者把"可能"写成"确定"？
- [ ] 每条引文的可核验程度标了吗？有没有编造任何出处？
- [ ] 无法核实的材料在正文里说明了吗？
- [ ] 文章的判断是用户自己的，还是我替他/她下的？（**课程类作业的核心判断必须属于作者本人**）
