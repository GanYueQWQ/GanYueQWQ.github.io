# 中文经济学与社科分析

这个技能只做两件在别处没有的事。**文风与废话不在这里管**——见下面的"分工"。

## 分工（不要越界）

| 任务 | 用哪个技能 |
| --- | --- |
| 通篇中文 AI 腔（对举句式、节奏均匀、抽象名词堆砌） | `humanizer-zh` |
| 决策类文本里的防御性免责声明、限定词堆叠 | `stss` |
| **经济学推理结构**（博弈要素、机制、预测） | **本技能** |
| **引文与档案的可核验程度** | **本技能** |
| 工程上的过度设计与范围蔓延 | `stop-that-shit` |

越界的典型错误：把一篇论证空心的文章润色得很自然；或者反过来，为了"去 AI 味"删掉必要的证据强度限定。**先保证论证站得住，文风是第二步。**

# 第一部分：经济学推理清单

跳过任何一项，懂经济学的读者都会看出来。

## 1. 先把博弈的要素摆出来，再讲道理

不要一上来就断言"这是囚徒困境"。按要素写清楚：

- **参与人**：谁在决策？**这一条最容易错**——层级不同博弈就不同（士兵个人 / 班排 / 营 / 司令部是四个不同的博弈）。
- **行动**：每人能选什么？
- **信息**：对方能看到什么、看不到什么？
- **支付**：**写出矩阵或排序**。数值可以按情形自设，但**必须说明"符号与大小顺序才是依据"**。不要只用"好处""坏处"这类词。
- **均衡**：纳什？子博弈精炼？贝叶斯？

一个 2×2 矩阵胜过三段形容词。举例（数值为示意）：

|  | 对方合作 | 对方背叛 |
| --- | --- | --- |
| 我合作 | 3 | −1 |
| 我背叛 | 4 | 0 |

写完之后**指明哪一格是哪个结果**，不要只贴矩阵不讲。

## 2. 先查占优策略，再谈"合作是均衡"

**最常见的硬伤**：说"合作是纳什均衡"却没说清占优策略是谁。

- 若**背叛**是占优策略而双方合作更好 → 囚徒困境（T > R > P > S，且 2R > T + S）。要解决的是"背叛的诱惑"。
- 若**合作**是占优策略 → 更像保证博弈／猎鹿（R > T > P > S）。要解决的是"对方会不会也来"的不确定性。
- 若 T > R > S > P → 斗鸡博弈。

**这两种情形的政策含义完全相反**：前者要改变支付或提高背叛成本，后者要降低协调风险、提供可信信号。搞错了，后面的建议全错。

## 3. 区分"均衡存在"与"均衡选择"

写出一个纳什均衡之后，**文章还没开始**。纳什均衡只说明"单方面改变没有好处"，它不解释"为什么走到这个均衡"。博弈里常有多个均衡（技术选择、位置博弈都有两个），真正要论证的是**哪一个会被选中、靠什么被选中**（历史、焦点、外部协调、先后行动）。

## 4. 讲清机制的三个前提

"合作能维持"需要三条，逐条检查文章是否交代：

- **激励**：未来够重要吗？重复的次数、贴现因子、关系的长度。
- **执行**：参与人**有没有能力**自己执行承诺的策略？如果他控制不了自己下一期的行动，机制失效——这是很多案例分析最有力的切入点。
- **信息**：对方能观察到我的行动吗？观察不到 = 隐藏行动；观察到但不知原因（如"被迫的背叛"） = 信号问题。

只写激励不写执行与信息，是这类文章最主要的单薄之处。

## 5. 把命题改写成可证伪的形式

不要停在"某理论有解释力但有局限"。写成：

> 原来的说法是 A。我的改法是 A′。**A′ 与 A 做出不同预测**：在情形 X 下 A 预测 …，A′ 预测 …。

写不出"改变了什么预测"，说明这只是措辞修补，不是分析。

## 6. 用这些标准收口

- **激励相容**：按这套安排行事，每个参与人自己的收益是否不吃亏？
- **帕累托有效**：这个均衡比哪个结果更好？还有更优的可行结果吗？
- **个人理性**：不能满足个人理性的制度安排实行不下去（不能靠"应该"维持）。
- **制度即均衡**：一种制度安排要发生效力，本身必须是一种纳什均衡。

## 7. 每个论断都要落到具体一格

写完一段自问：这句在说哪一格收益、哪一次选择、哪一层参与人？落不到位置的，多半是空话，改实或删掉。

## 8. 层级不要串

谈个人理性与集体理性冲突时，**说清是哪个集体**。"军队/国家/社会"的集体利益可能和个人的相反。典型写法：

> 对士兵个人来说……；对司令部来说……。两者激励方向相反，而后者能覆盖前者的均衡。

把两个层级塞进一句话，论证会崩。

# 第二部分：来源核实纪律

社科与经济学文章的可信度全在这里。**每条引文标明可核验程度**：

| 标记 | 含义 | 正文里怎么写 |
| --- | --- | --- |
| **已核对原文** | 直接读到转录/原文，逐字对齐 | 正常引用，必要时注明版本或档案号 |
| **二手** | 只有研究著作或机构网页的转述 | 注明"转引自"，或避免据此下判断 |
| **无法核实** | 穷尽检索没读到 | **必须写明**，并给档案号/存档途径供读者自查 |
| **未采用** | 查不到可靠出处 | 不用它，但可说明为何不用 |

**硬规则：**

1. **绝不编造引文、档案号、页码、URL、数字、日期。** 一处编造毁掉整篇可信度。
2. **区分"无法核实"与"有误"。** 检索不到不等于史料错了。
3. **流行说法若无出处，就明确标注并说明不采用的条件**——这比默默使用强得多。
4. **网页可能已下架**：写"该页面已下架（返回 410）"并给档案号或存档说明，别把死链当引用。
5. **引课件要带页码**：哪一次讲义、第几页、什么内容。
6. **在正文里说出核实限度**会增加可信度："以下两条引文逐字核对过，这一条没有。"

# 工作流程

1. **问清三件事**，缺一件不要动笔：
   - 要检验的**观点原文**是什么？（课件/笔记拿来）
   - 有没有**必须用的材料**（案例、数据、指定文献）？
   - **提交场合**：字数、格式、是否要参考文献、是否需要论点立场？
2. **先搭论证骨架**：按第一部分八项走一遍，写出支付矩阵、占优策略、条件分析、预测差异。**骨架不过关就不要润色文字。**
3. **再写文字**：涉及中文 AI 腔的处理交给 `humanizer-zh` 的清单；涉及防御性废话交给 `stss`。
4. **最后核来源**：逐条标记，把无法核实的写进正文的限度说明。
5. **交付说明**：论证靠什么、哪些来源待核、哪部分是用户必须自己拿的判断。

## 可选：量化自检

`scripts/zh_style_check.py` 输出可复现指标，其中**内容配比**一栏用于检查"经济学文章有没有在讲经济学"：

```bash
python scripts/zh_style_check.py 稿件.typ            # 支持 .typ/.md/.txt
python scripts/zh_style_check.py 旧稿.typ 新稿.typ    # 自动前后对比
```

它统计：段落与句长变异系数、对举句密度、限定词密度、抽象/具体词比、引号引用数，以及**经济学词 vs 史实词的配比**。文风指标的解释权在 `humanizer-zh`，本脚本只提供数字。

# 交付前核对

- [ ] 博弈要素写全了吗？支付矩阵或排序写出来了吗？符号与顺序说明了吗？
- [ ] **占优策略查了吗**？是囚徒困境还是保证博弈，说清了吗？
- [ ] 讲清"均衡选择"了吗，还是只证明了均衡存在？
- [ ] 激励、执行、信息三条都交代了吗？
- [ ] 我的改法**改变了什么预测**？
- [ ] 每个论断能落到具体某一格、某一层参与人吗？
- [ ] 每条引文标了可核验程度吗？有没有编造任何出处？
- [ ] 无法核实的材料在正文里说明了吗？
- [ ] **核心判断是用户自己的吗？**（课程作业的立场必须属于作者本人，不能代下结论）
